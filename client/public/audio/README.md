# Audio assets

Place MP3 files here (filenames match `AUDIO_FILES` in `client/src/AudioControl.tsx`):

| File | Use |
|------|-----|
| `music-menu.mp3` | Home, draft, and screens without the main board |
| `music-game.mp3` | Main board / in-game section |
| `checked.mp3` | Loops for 3 of your turns after you are put in check |
| `check.mp3` | Loops for 3 of your turns after you put the opponent in check |
| `sfx-ui.mp3` | Buttons outside the board |
| `sfx-piece.mp3` | Board square / piece clicks |
| `sfx-card-cast.mp3` | Casting a spell card |

Missing files are ignored until you add them. Toggle Music / SFX with the buttons above FX (bottom-right).
